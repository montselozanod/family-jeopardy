# Carpeta para media de preguntas

Coloca aquí las imágenes y videos para las preguntas de trivia.

## Formato de nombres sugerido
- `{id}-descripcion.jpg` - Ej: `37-flavor-flav.jpg`
- `{id}-descripcion.mp4` - Ej: `42-tibia-gameplay.mp4`

## Tipos soportados
- **Imágenes**: jpg, png, gif, webp
- **Videos**: mp4, webm
- **YouTube**: Usa URLs directamente en los datos
